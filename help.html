🧮 中小学数学动画讲解怎么用

  1. 打开 中小学数学，选年级。
  2. 输入题目（三选一）：打字直接写 / 🎤 语音输入对着手机说 / 📷 拍照识别拍作业本。

📷 高数拍照答题怎么用

  1. 打开 高数拍照答题，选科目（高等数学/线性代数）。
  2. 点"📷 拍照答题"，把题目拍清楚（印刷体识别最好）。
  3. 识别出文字后检查一遍，点"生成详细解答"。
  4. 得到：思路分析 → 分步推导 → 易错点 → 总结。想看别的思路点"换种解法"。

家长不会打字怎么办

  • 语音输入：点 🎤 按钮，对着手机说话就行（需用 Chrome / Edge 打开，微信里可能不支持）。
  • 拍照识别：点 📷 按钮，直接拍作业本，文字自动填进去。
  • 识别完务必检查一遍文字，手动改对了再用。
