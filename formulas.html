极限与连续 · 速查

等价无穷小替换只可用于乘除因子，加减慎用

两个重要极限

$\lim\limits_{x\to0}\dfrac{\sin x}{x}=1$三角型基础
$\lim\limits_{x\to\infty}\left(1+\dfrac{1}{x}\right)^x=e$幂指型（1^∞ 必用）

常用等价无穷小（x→0）

$\sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim x$四大等价
$1-\cos x \sim \dfrac{x^2}{2}$二阶必背
$e^x-1 \sim x,\quad \ln(1+x)\sim x$指数对数互逆
$(1+x)^a-1 \sim ax$幂型推广
$x-\sin x \sim \dfrac{x^3}{6},\quad \tan x - x \sim \dfrac{x^3}{3}$三阶常用（加减差型）
$\tan x-\sin x \sim \dfrac{x^3}{2}$提公因式后用

洛必达适用条件

$\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$，且导数比极限存在或为 ∞三个条件缺一不可

导数与中值定理 · 速查

求导法则

$(uv)'=u'v+uv'$乘积法则
$\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^2}$商法则（减号别丢）
$\{f[g(x)]\}'=f'[g(x)]\cdot g'(x)$链式法则（由外到内）
$(x^y)'$ 对 $x$：视 $y$ 为常数，$=y x^{y-1}$幂指函数分方向

三大中值定理（条件 → 结论）

罗尔：$f(a)=f(b) \Rightarrow \exists \xi,\ f'(\xi)=0$端点相等是标志
拉格朗日：$f'(\xi)=\dfrac{f(b)-f(a)}{b-a}$「割线斜率=切线斜率」
柯西：$\dfrac{f'(\xi)}{g'(\xi)}=\dfrac{f(b)-f(a)}{g(b)-g(a)}$双函数比值

导数应用

极值可疑点：$f'(x_0)=0$ 或 $f'$ 不存在处两判法：一阶变号 / 二阶正负
$f''(x_0)>0$ → 极小；$f''(x_0)<0$ → 极大二阶判别（$f'(x_0)=0$ 时）
拐点：$f''$ 变号处要求 $f''=0$ 或不存在 + 变号
$\dfrac{E}{Q}=\dfrac{P}{Q}\dfrac{dQ}{dP}$弹性（数三）

一元积分 · 速查

基本积分公式

$\int \dfrac{dx}{x}=\ln|x|+C$绝对值常被漏
$\int \dfrac{dx}{a^2+x^2}=\dfrac{1}{a}\arctan\dfrac{x}{a}+C$arctan 型
$\int \dfrac{dx}{x^2-a^2}=\dfrac{1}{2a}\ln\left|\dfrac{x-a}{x+a}\right|+C$分式拆解型
$\int \sqrt{a^2-x^2}\,dx=\dfrac{x}{2}\sqrt{a^2-x^2}+\dfrac{a^2}{2}\arcsin\dfrac{x}{a}+C$三角换元结果

方法选择顺序

① 凑微分 → ② 换元（根式/三角） → ③ 分部积分「反对幂三指」越靠前越当 $u$
$\int u\,dv=uv-\int v\,du$分部（符号别反）

变限积分与定积分性质

$\left(\displaystyle\int_a^{g(x)}f(t)dt\right)'=f[g(x)]\cdot g'(x)$上限是谁就代谁 × 上限导
奇函数在对称区间积分为 $0$对称性先看（秒杀神器）
$\displaystyle\int_{-a}^{a}f=2\int_0^a f\quad$（$f$ 偶）偶函数折半
周期：$\displaystyle\int_a^{a+T}f=\int_0^T f$与起点无关

多元微分 · 速查

链式法则

$z=f(u,v),\ u=\varphi(x,y),\ v=\psi(x,y)$画树形图，路路相乘再相加
$\dfrac{\partial z}{\partial x}=\dfrac{\partial z}{\partial u}\dfrac{\partial u}{\partial x}+\dfrac{\partial z}{\partial v}\dfrac{\partial v}{\partial x}$两条路径之和

隐函数求导

$F(x,y)=0:\ \dfrac{dy}{dx}=-\dfrac{F_x}{F_y}$负号常漏
$F(x,y,z)=0:\ \dfrac{\partial z}{\partial x}=-\dfrac{F_x}{F_z}$对谁求导其余视为常数

极值（数一/三重点）

$A=f_{xx},\ B=f_{xy},\ C=f_{yy};\ \Delta=AC-B^2$驻点处计算
$\Delta>0,A<0$ 极大；$\Delta>0,A>0$ 极小；$\Delta<0$ 非极值判别三连

微分方程 · 速查

一阶方程识别

可分离：$y'=f(x)g(y) \Rightarrow \int\dfrac{dy}{g(y)}=\int f(x)dx$先分离再两边积
一阶线性：$y'+P(x)y=Q(x)$直接套公式
$y=e^{-\int P dx}\left(\int Q e^{\int P dx}dx + C\right)$通解公式

二阶常系数齐次

$r^2+pr+q=0$ 两不等实根：$y=C_1e^{r_1x}+C_2e^{r_2x}$特征方程先解
重根 $r$：$y=(C_1+C_2x)e^{rx}$补一个 $x$
共轭复根 $\alpha\pm\beta i$：$y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$cos+sin 成对出现

无穷级数 · 速查 数一/数三

敛散判别

$\sum q^n$：$|q|<1$ 收敛；$p$ 级数：$p>1$ 收敛两大标尺
比较：$0\le a_n\le b_n$，大收小收，小散大散比较对象别选错
比值：$\lim\dfrac{a_{n+1}}{a_n}=\rho<1$ 收敛含 n! / a^n 首选

幂级数

$R=\dfrac{1}{\rho},\ \rho=\lim\left|\dfrac{a_{n+1}}{a_n}\right|$收敛半径（端点单独验）
$\dfrac{1}{1-x}=\sum_{n=0}^{\infty}x^n,\ |x|<1$展开基石
$e^x=\sum\dfrac{x^n}{n!},\ \sin x=\sum(-1)^n\dfrac{x^{2n+1}}{(2n+1)!}$两大万能展开

线性代数 · 速查 数一/二/三

行列式

$\left|A^T\right|=\left|A\right|,\quad \left|AB\right|=\left|A\right|\cdot\left|B\right|$转置不变，乘积可拆
$\left|kA\right|=k^n\left|A\right|,\quad \left|A^{-1}\right|=\dfrac{1}{\left|A\right|}$数乘提 k 的 n 次方
$\left|A^*\right|=\left|A\right|^{n-1}$伴随的行列式
副对角行列式 $=(-1)^{\frac{n(n-1)}{2}}\prod a_{i\,(n+1-i)}$n=2、3 时为负
范德蒙德 $V_n=\prod_{1\le i下标大的减小的

矩阵运算与秩

$A^{-1}=\dfrac{1}{\left|A\right|}A^*,\quad AA^*=A^*A=\left|A\right|E$伴随矩阵万能公式
$(AB)^{-1}=B^{-1}A^{-1},\quad (AB)^T=B^TA^T$取逆/转置均反序
$r(A+B)\le r(A)+r(B),\quad r(AB)\le\min\{r(A),r(B)\}$和秩不超和、积秩不增
$r(AB)\ge r(A)+r(B)-n$（$A$ 为 $m\times n$）Sylvester 下界
$r(A^TA)=r(A)$列满秩关键结论

线性方程组

齐次 $Ax=0$：基础解系含 $n-r(A)$ 个解向量解空间维数
非齐次 $Ax=b$：$r(A)=r(A\,|\,b)$ 有解；$=n$ 时唯一解有解判定两问
通解 $=$ 特解 $+$ 齐次通解解的结构

特征值与二次型

$\left|\lambda E-A\right|=0,\quad A\xi=\lambda\xi$特征方程求特征值/向量
$\sum\lambda_i=\mathrm{tr}(A),\quad \prod\lambda_i=\left|A\right|$特征值之和=迹，之积=行列式
$A$ 可对角化 $\iff$ 有 $n$ 个线性无关特征向量；实对称矩阵必可正交对角化对角化判定
正定：各阶顺序主子式全 $>0$；或 $x^TAx>0\ (x\ne0)$正定判别

概率统计 · 速查 数一/三

概率公式

$P(A\cup B)=P(A)+P(B)-P(AB)$加法公式
$P(AB)=P(B)P(A\mid B)$乘法公式
全概率 $P(A)=\sum_i P(B_i)P(A\mid B_i)$完备事件组加权
贝叶斯 $P(B_j\mid A)=\dfrac{P(B_j)P(A\mid B_j)}{\sum_i P(B_i)P(A\mid B_i)}$由果溯因
独立：$P(AB)=P(A)P(B)$；伯努利 $P(X=k)=C_n^k p^k(1-p)^{n-k}$独立 + n 重试验

常见分布

二项 $X\sim B(n,p)$：$E(X)=np,\ D(X)=np(1-p)$n 重伯努利
泊松 $X\sim P(\lambda)$：$P(X=k)=\dfrac{\lambda^k e^{-\lambda}}{k!}$，$E=D=\lambda$稀有事件
均匀 $U(a,b)$：$f(x)=\dfrac{1}{b-a}$，$E=\dfrac{a+b}{2}$区间等可能
指数 $E(\lambda)$：$f(x)=\lambda e^{-\lambda x}$，$E=\dfrac{1}{\lambda}$无记忆性
正态 $N(\mu,\sigma^2)$：$f(x)=\dfrac{1}{\sqrt{2\pi}\,\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$，$\dfrac{X-\mu}{\sigma}\sim N(0,1)$标准化是核心

数字特征

$E(X)=\sum x_ip_i=\int_{-\infty}^{+\infty}xf(x)dx$均值定义（离散/连续）
$D(X)=E(X^2)-(EX)^2,\quad D(aX+b)=a^2D(X)$方差公式与性质
$\mathrm{Cov}(X,Y)=E(XY)-E(X)E(Y)$协方差
$\rho_{XY}=\dfrac{\mathrm{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$相关系数（$|\rho|\le1$）
切比雪夫：$P\left(|X-E(X)|\ge\varepsilon\right)\le\dfrac{D(X)}{\varepsilon^2}$概率上界
中心极限：$\dfrac{\sum_{i=1}^{n}X_i-n\mu}{\sqrt{n}\,\sigma}\xrightarrow{d}N(0,1)$n 大时近似正态

数理统计

$\bar X=\dfrac{1}{n}\sum X_i,\quad S^2=\dfrac{1}{n-1}\sum(X_i-\bar X)^2$样本均值/方差（无偏）
$\chi^2,\ t,\ F$ 三大抽样分布与正态总体抽样定理数一
矩估计：样本矩=总体矩；极大似然：求 $L(\theta)$ 最大点点估计两法
无偏：$E(\hat\theta)=\theta$评选标准

易混点对比 · 8 组高频陷阱

左：正确理解 / 右：典型错误 — 考场上先对照自查
无穷小（某过程极限为 0）任意小但趋于 0 的变量
如 $x\to0$ 时 $x^2,\ \sin x$
❌ 有界量 ≠ 无穷小$\sin\frac1x$（x→0）有界但极限不存在
无穷小必收敛；有界可振荡
可导 ⟹ 连续一元：可导、可微、连续关系链
可导 ⟺ 可微 ⟹ 连续 ⟹ 极限存在
❌ 连续 ⇏ 可导$y=|x|$ 在 0 连续不可导
连续只是必要条件
多元：可微 ⟹ 偏导存在 + 连续可微是「全增量线性近似」
检查 $f(\Delta x,\Delta y)-f_x\Delta x-f_y\Delta y=o(\rho)$
❌ 偏导存在 ⇏ 可微偏导存在连连续都推不出
多元关系整体弱于一元
$\lim$ 存在 ⟺ 左右极限存在且相等分段点必验
$e^{1/x}$ 型分左右（0⁻→0, 0⁺→+∞）
❌ 导数极限 ≠ 导数存在$f'=\lim\frac{f(x)-f(x_0)}{x-x_0}$ 必须用定义
洛必达结果存在≠原极限存在时不可逆推
绝对收敛 ⟹ 收敛$\sum|a_n|$ 收敛则原级数收敛
交错级数用莱布尼茨判收敛
❌ 收敛 ⇏ 绝对收敛$\sum(-1)^{n-1}\frac1n$ 条件收敛
条件收敛：收敛但绝对值发散
罗尔：f(a)=f(b)结论 $f'(\xi)=0$
见到端点相等就用罗尔（或构造 F）
❌ 拉格朗日 ≠ 罗尔拉氏结论含 $\frac{f(b)-f(a)}{b-a}$
证明「ξ 处导数=某定值」选对定理
变限求导：代上限$\left(\int_0^{g(x)}f\right)'=f[g(x)]\cdot g'(x)$
只有「上限是被积变量函数」才需要链式
❌ 「减下限」多余操作$\int_a^x f$ 求导不需要 $-f(a)$
定积分值是常数，求导规则别套错
一致收敛 / 一致连续（数一）$\forall\varepsilon\ \exists\delta$ 与点无关
闭区间连续必一致连续（Cantor）
❌ 逐点 ⟹ 一致$x^n$ 在 (0,1) 逐点收敛 0 但不一致
端点行为是判断关键
